# Adam Asmaca

Python öğrenirken yazdığım Türkçe kelimelerle oynanan konsol oyunu. Rastgele kelime seçimi, kullanılan harfler ve kalan hakları takip etme üzerine çalıştım.

```bash
python AdamAsmaca/AdamAsmaca.py
```

Python 3 dışında paket gerekmiyor. `.sln` ve `.pyproj` dosyaları eski Visual Studio kurulumundan; oyunu çalıştırmak için gerekli değiller.
